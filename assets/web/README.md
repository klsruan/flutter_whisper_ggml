# Generated WebAssembly artifacts

`flutter_whisper_worker.js` is source-controlled. The following files are
generated by `tool/build_web_wasm.ps1` and must be copied here before running
real browser inference:

- `flutter_whisper.js`
- `flutter_whisper.wasm` when `SINGLE_FILE` is disabled

Large GGML model files are application assets or remote URLs and are not
bundled with the plugin.
