# Minimal smoke test

This intentionally small application validates `flutter_whisper_ggml` on
Android, iOS, Linux, macOS, Web and Windows. Select a GGML model and a WAV file,
then run one transcription. It contains no model and no FFmpeg dependency.

The full-featured example lives in the separate
[`flutter_whisper_ggml_example`](https://github.com/klsruan/flutter_whisper_ggml_example)
repository.
